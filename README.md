# 九轉丹房 · 修仙煉丹模擬器

單頁網頁遊戲（`index.html`），唔使安裝，直接用瀏覽器開。

## 玩法
1. **丹方**：揀丹道（正道／魔道／毒道／佛門／醫道）、心法、火種、火候（一至九）、丹爐。
2. **藥櫃**：撳藥材放入丹爐。第一味係「君藥」，應該放最猛嗰味；相鄰藥材五行相生有加成，相剋會令丹爐唔穩。
3. **開爐煉丹**：九轉之後出丹，或者炸爐。
4. **處理丹藥**：食、搵師弟試藥、或者賣去丹閣／黑市換靈石。

食丹會影響修為、毒素、心魔、壽元。毒素或心魔到 100、壽元耗盡、或者食咗太高品嘅丹（虛不受補）都會死。修為滿可突破境界，一路去到飛升。
